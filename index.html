01 / 04● live system

REAL-TIME WEB APP

HowFar

01

"How Far” is a sleek, real-time chat application built to showcase WebSocket-based communication with a modern and responsive UI. The backend is powered by FastAPI, enabling live messaging, user join/leave notifications, an online users counter, and message timestamps. On the front-end side, a lightweight HTML/CSS/JavaScript client connects to the WebSocket endpoint, allowing multiple users to chat instantly and seamlessly across devices. The design is mobile-friendly, fast and minimal, making it ideal both as a demonstration of real-time web communication and as a foundation for more advanced features such as authentication, private rooms or message persistence.

02 / 04● browser app

FRONTEND SYSTEM

Student Management System

02

The app focuses on creating a smooth and enjoyable user experience by efficiently handling updates to the DOM without page reloads. Every action—from typing a new task to marking one as completed—happens instantly, giving it a dynamic feel similar to modern single-page applications. Although it doesn’t use a backend, all operations run directly in the browser, making it fast, lightweight, and easy to deploy as a static web app. The project also demonstrates a solid understanding of front-end logic, event handling, and state management using only vanilla JavaScript, without relying on external frameworks. This project highlights practical front-end development skills such as layout design, responsive styling, and DOM manipulation while maintaining clean, maintainable, and readable code. It serves as a foundation for future upgrades like task persistence using localStorage, task filtering, or integration with backend APIs.
